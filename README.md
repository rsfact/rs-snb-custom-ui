# Scanners Base ｜ スキャン基盤サービスの使い方

## 概要

スキャン資料の保存・AIによる読み取り・カスタム閲覧画面を提供するシステムです。

---

## ログイン

- 発行されたID・パスワードでログインしてください。

---

## ドキュメントのアップロード

- ドキュメントは個別のURLからアップロードします。URLごとにブックマークしてご利用ください。
- **フォルダ**を作成し、右下の「+」ボタンからアップロードします。  
  （対応形式：**PNG, JPEG**。追加アップロードも可能です）
- アップロード後、設定されているモードにより**自動で内容が読み取られます**。この設定はURLごとに異なり、別のURLでアップロードすると正しく読み取られません。
- 読み取り設定がない場合は、単に保存のみとなります。

**例:**  
お客様にアカウントを発行し、「月ごとにフォルダ（例：202611領収書）を作成するので、毎月該当フォルダにアップロードしてください」とご案内。お客様は任意のタイミングでアップロードし、内容のAI読み取りまで自動で完了します。

---

## ドキュメントの閲覧

- アップロード済みドキュメントを全文検索できます。
  - フォルダ内検索・フォルダ横断の全体検索の両方に対応⭕️
- 電子帳簿保存法に対応するドキュメントは、**取引先名・発行日・金額**ごとに詳細検索できます。

---

## ドキュメントの項目編集

- 読み取られた項目は修正可能です。対象ドキュメントをクリックして編集してください。
    - **読み取りエラー**：Difyによる読み取りが失敗したドキュメント
    - **チェック済**：「保存」ボタンを押す、または別ページに遷移した時点で適用されます。

---

## よくある使い方

1. ブックマークしておいたリンク（例：{BASE_URL}/snb/boards/receipt-firmA）を開く
2. 「2025年11月分」など新規フォルダを作成
3. 本日分のドキュメント50枚をアップロード
4. AIの読み取りを待つ
5. 読み取り結果を確認・エラーがある場合は該当ドキュメントをクリックして編集
6. 翌日、同じフォルダに追加分70枚をアップロード→同様
7. B社の領収書はB社用の別ページから同様の操作を行う

---

## 管理者の方へ

### コンソール画面

- 読み取りAIの設定ルールを定義できます。
- カスタム画面作成時に使用するもので、通常業務では触れる必要はありません。

### カスタム画面

- 任意のUIデザインや追加機能（CSVエクスポート等）を作成し、お客様向けに公開できます。
- お客様向けリンクは、次のどちらの形でも開けます（画面の作り方により管理者・エンジニアが選びます）。
  - **ボード全体** … `?board_id=...` のみ（フォルダ一覧から選んで閲覧するタイプ）
  - **特定フォルダ** … `?board_id=...&task_id=...`（そのフォルダを最初から開くタイプ。SNB 本体のフォルダ右下ペーパークリップからコピーする専用コードは通常こちら）
- ログインは Scanners Base と同じID・パスワードです。

<aside>
管理者がカスタム画面を調整・完成 → エンジニアにコードを渡してリンク化を依頼（実装コストゼロ）→ お客様にURLとアカウント情報を共有 → お客様がリンクからログインして閲覧
</aside>
